用户报错最可能 3 原因：① 不在 ai_trust_layer 目录跑（requirements.txt/app.py 找不到）② pip 和 streamlit 不同 python 环境（pip 装系统 python，streamlit 命令用别的）③ 路径格式问题。待用户贴报错精准定位。
