## 诊断：streamlit 报错排查（2026-07-25 07:38）

用户报 `pip install -r requirements.txt && streamlit run app.py` 报错。沙箱排查结论：**代码完全正常，报错是环境/路径问题**。

验证链：
1. 所有 .py 语法 OK（py_compile 全过）

**关键经验（跨项目可复用）**：workbuddy venv 的 pip/streamlit 是 Windows exe，**不识别 Git Bash 的 /e/ 路径**，必须用 Windows 路径（`E:/...` 或 `E:\...`）。我第一次装依赖就踩了这个坑：`pip install -r '/e/...'` 报 "Could not open requirements file"，改 `E:/...` 立刻成功。

用户报错最可能 3 原因：① 不在 ai_trust_layer 目录跑（requirements.txt/app.py 找不到）② pip 和 streamlit 不同 python 环境（pip 装系统 python，streamlit 命令用别的）③ 路径格式问题。待用户贴报错精准定位。
