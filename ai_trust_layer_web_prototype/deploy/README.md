# AI Trust Layer — Static Deployment Package

- 8 pages total, all internal links use relative paths
- Dependencies: Tailwind CSS v4 and Lucide icons, loaded via CDN (network required)

Upload the files **inside** this folder as the site root — not the `deploy/` folder itself.
