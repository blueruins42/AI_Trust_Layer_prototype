Jargon Explanation

"CBTC"

💬 It uses radio to let trains and wayside equipment chat in real time, so the system always knows where each train is and how fast it is going.

📖 Formal definition

Communication-Based Train Control, a train control system based on continuous train-to-ground communication.

"Moving block"

💬 The safe gap between trains is not fixed; it is calculated on the fly—faster trains get more space, stopped trains can be closer.

📖 Formal definition

Moving Block, a block system in which the safe separation between trains is calculated dynamically based on real-time speed.
