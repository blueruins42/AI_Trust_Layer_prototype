## Page 1: Project Overview

This project is the low-voltage integration of the signaling system for XX Urban Rail Transit Line 2, with a total line length of 28.5km, 22 stations, and 1 depot. The project covers design, supply, installation, commissioning, and integrated testing of signaling, communication, security, and comprehensive monitoring systems.

Main engineering scope includes:
- CBTC signaling system design and integration
- Interlocking system equipment supply and installation
- Track circuit and balise layout
- Onboard ATC equipment configuration

## Page 15: Signaling System Technical Specifications

The signaling system adopts CBTC (Communication-Based Train Control) technology. Core equipment includes:

1. **Automatic Train Protection (ATP) Subsystem**: Achieves train spacing control and overspeed protection, with a minimum headway of 90 seconds.
2. **Automatic Train Operation (ATO) Subsystem**: Achieves automatic train driving and precise stopping, with a stopping accuracy of +/-0.3m.
3. **Computer Interlocking System**: Achieves interlocking control of switches, signals, and track circuits.
4. **Data Communication System (DCS)**: Uses waveguide + leaky cable for train-to-ground communication.

Signals use LED light sources, switch machines use ZDJ-200 electric switch machines, and track circuits use audio frequency digital track circuits.
